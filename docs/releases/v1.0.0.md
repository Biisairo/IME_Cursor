ImeCursor의 첫 릴리즈입니다. 현재 키보드 입력 소스를 마우스 포인터 옆과 텍스트 캐럿 옆에 배지로 보여 주는 macOS 메뉴바 앱입니다.

## 주요 기능

- 마우스 포인터 옆의 커서 배지. 입력 소스마다 글자와 모양을 설정할 수 있습니다.
- 텍스트 캐럿 옆의 캐럿 배지(선택). 타이핑하는 동안에도 입력 소스를 확인할 수 있습니다. 접근성 권한이 필요합니다.
- 기준 방향(3 × 3)과 간격으로 배지 위치 지정
- 기본 스타일 공유, 입력 소스별로 바꾼 항목만 덮어쓰기
- Caps Lock 표시, 전환 강조, 표시 모드

## 설치

1. `ImeCursor-1.0.0.zip`을 받아 압축을 풉니다.
2. `ImeCursor.app`을 `/Applications`로 옮깁니다.
3. 이 앱은 ad-hoc 서명만 있고 공증을 받지 않았습니다. 처음 실행할 때 macOS가 실행을 막으면 다음 가운데 하나를 합니다.
   - 시스템 설정 → 개인정보 보호 및 보안에서 **그래도 열기**를 누릅니다.
   - 터미널에서 `xattr -dr com.apple.quarantine /Applications/ImeCursor.app`을 실행한 뒤 다시 엽니다.

요구 사항: macOS 14 (Sonoma) 이상

---

The first release of ImeCursor, a macOS menu bar app that shows the current keyboard input source as a badge next to the mouse pointer and the text caret.

- Cursor badge next to the mouse pointer, with a label and style for each input source
- Optional caret badge next to the text caret (needs Accessibility permission)
- Badge position by direction (3 × 3 grid) and offset
- Shared default style with per-source overrides
- Caps Lock indicator, switch emphasis, display modes

To install, unzip `ImeCursor-1.0.0.zip` and move `ImeCursor.app` to `/Applications`. The app has only an ad-hoc signature and is not notarized. If macOS blocks the first launch, click **Open Anyway** in System Settings → Privacy & Security, or run `xattr -dr com.apple.quarantine /Applications/ImeCursor.app`.

Requires macOS 14 (Sonoma) or later.
