## 변경 사항

- **안정성:** 다른 앱이 접근성 API로 예상과 다른 형식의 값을 돌려주면 ImeCursor가 종료될 수 있던 문제를 고쳤습니다. 이제 값의 형식을 먼저 확인하고, 형식이 다르면 그 값을 쓰지 않습니다.
- **캐럿 배지 기본 위치:** 캐럿의 오른쪽(→)에서 오른쪽 위(↗)로 바꿨습니다. 캐럿 배지는 캐럿보다 조금 늦게 따라오므로, 오른쪽에 있으면 방금 입력한 글자를 가렸습니다. 이 기본값은 새로 설치할 때만 적용됩니다. 이미 쓰고 있다면 설정 → 기본 스타일 → 캐럿 배지 위치 기본값에서 ↗를 고르세요.

## 설치

1. `ImeCursor-1.0.1.zip`을 받아 압축을 풉니다.
2. `ImeCursor.app`을 `/Applications`로 옮깁니다. 이전 버전을 덮어써도 설정은 유지됩니다.
3. 이 앱은 ad-hoc 서명만 있고 공증을 받지 않았습니다. 처음 실행할 때 macOS가 실행을 막으면 다음 가운데 하나를 합니다.
   - 시스템 설정 → 개인정보 보호 및 보안에서 **그래도 열기**를 누릅니다.
   - 터미널에서 `xattr -dr com.apple.quarantine /Applications/ImeCursor.app`을 실행한 뒤 다시 엽니다.
4. 캐럿 배지를 쓰고 있었다면, 새 앱은 서명이 달라서 접근성 권한을 다시 허용해야 합니다.

요구 사항: macOS 14 (Sonoma) 이상

## Changes

- **Stability:** Fixed a problem where ImeCursor could quit when another app returned a value of an unexpected type through the Accessibility API. ImeCursor now checks the type first and ignores values of the wrong type.
- **Default caret badge position:** Changed from the right of the caret (→) to above and to the right (↗). The caret badge follows the caret with a small delay, so at the right it covered newly typed text. This default applies only to new installs. If you already use ImeCursor, select ↗ in Settings → 기본 스타일 (Default style) → caret badge position default.

## Install

Unzip `ImeCursor-1.0.1.zip` and move `ImeCursor.app` to `/Applications`. Your settings stay when you replace an earlier version. The app has only an ad-hoc signature and is not notarized. If macOS blocks the first launch, click **Open Anyway** in System Settings → Privacy & Security, or run `xattr -dr com.apple.quarantine /Applications/ImeCursor.app`. If you use the caret badge, allow Accessibility permission again, because the new app has a different signature.

Requires macOS 14 (Sonoma) or later.
